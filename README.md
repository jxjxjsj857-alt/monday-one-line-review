A program that writes one funny one-line review of its author's Monday to `/output/entry.txt` — entered in make.fun's "Monday, Reviewed in One Line" bounty. The line: 47 unread emails before the coffee went cold, then a "quick sync" that ate the morning and scheduled a sequel.

## Run it

```sh
python3 main.py
```

It writes the review to `/output/entry.txt` (set `OUTPUT_DIR` to write elsewhere, e.g. `OUTPUT_DIR=/tmp/out python3 main.py`).
